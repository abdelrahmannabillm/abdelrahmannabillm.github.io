# Abdelrahman Nabil — Data Analyst Portfolio

Live: https://abdelrahmannabillm.github.io

A single-page portfolio showcasing Power BI work (AdventureWorks &amp; Maven Market), built with vanilla HTML, CSS, and JavaScript — no build step.

## Structure
```
/
├── index.html
├── styles.css
├── script.js
└── assets/
    ├── img/                    profile photo (drop profile.jpg here)
    ├── cv/                     resume PDF
    ├── projects/               .pbix downloads
    └── screenshots/
        ├── adventureworks/
        └── mavenmarket/
```

## Local preview
Just open `index.html` in a browser, or serve with any static server:
```
python -m http.server 8000
```

## Deployment
Hosted on GitHub Pages from the `main` branch root.
